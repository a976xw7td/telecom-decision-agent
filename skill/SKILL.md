# 经营决策 Skill 包 v1.0.0

归属 Agent：`agent.telecom-ops-decider` v1.0.0（build 20261125.3）
定位：把「看数 → 判断 → 追问 → 加人/调整 → 证据校验」拆成 5 个可单独验证的 Skill，再由 1 条工作流串起来。

---

## Skill ① `structured-weekly-judgment` v1.0.0 · 经营周报结构化判断

**触发**：用户问「本周经营怎么样 / 为什么转负 / ARPU 变化」等周报类问题。
**五段流水线**（界面同步点亮）：

1. `输入校验`：时间窗、对象范围、分析维度、决策目的四槽位检查。
2. `RAG 检索(口径知识源)`：`retrieve(query, 3)` 在 KB-01~KB-12 上做关键词加权检索，返回命中条目、分数与原文。
3. `指标计算`：`metrics()` 复算净增率、ARPU 变化、5G 渗透率、万投比、融合离网率、单户酬金、连续为负周数。
4. `证据充分性校验`：见 Skill ⑤ 双闸门。
5. `结构化结论输出`：结论 / 依据（含 KB 编号与算式）/ 待补证据三段。

**硬规则**
- 不输出没有 KB 编号支撑的数字。
- 未核验的假设必须标 `verified=false`，不得写成结论。
- 5 周数据不得外推季节性。

## Skill ② `slot-clarify` v1.0.0 · 多轮澄清

四槽位：`window`（时间窗）/ `scope`（对象范围）/ `dimension`（分析维度）/ `purpose`（决策目的）。

| 轮次 | 输入 | 行为 |
| --- | --- | --- |
| 第 1 轮 | 「帮我看看情况」 | `clarify`，反问 4 个槽位，**不下结论** |
| 第 1 轮 | 「本周经营怎么样？」 | `clarify`，`window` 已被「本周」填充，只缺 3 个槽位 |
| 第 2 轮 | 补齐范围/维度/目的 | `judgment`，进入判断 |

规则：缺槽先问；用户补充后只问仍在缺的槽，不重复追问已填槽位。

## Skill ③ `whatif-staffing` v1.0.0 · What-if 加人测算

- 基线月挽留：`6 户/人/日 × 人数 × 22 工作日` → 3 人 = **396 户/月**
- 新人月挽留：人均产能打 3 折 → 3 人 = **102 户/月**
- 带教机会成本：**60 户/月**（老员工带新人让出的产能）
- 净增：`102 − 60 = 42 户/月`，覆盖率提升 **10.61%**
- 敏感性（毛利口径缺失时的替代展示）：`20/30/40 元毛利 → 840/1260/1680 元月毛增 → 19/12.7/9.5 个月回本`

**边界**：缺毛利率与单户成本时**不输出 ROI 结论**，只给回本区间并标注假设。

## Skill ④ `staffing-adjust` v1.0.0 · 人员不可用调整

| 场景 | 规则 | 输出 |
| --- | --- | --- |
| 在岗率 | ≥ 60% 可开班，否则并班 | 3 人请假 1 人 → 66.7% → 可开班 |

| 动作 | 每条必须带责任人 | 班组长 / 经营分析岗，共 4 条 |

## Skill ⑤ `evidence-guard` v1.0.0 · 证据充分性守卫（双闸门）

```
allow  ⇔  (口径命中最高分 ≥ 3)  AND  (样本达下限：≥500 户 且 ≥30 单)
block  ⇔  任一不满足 → 只输出待补证据清单 + 取证路径
```

三条已验证分支：

| 输入 | 闸门结果 | 输出 |
| --- | --- | --- |
| 「竞品降价 30%，是否跟进」 | 口径未命中且无竞品价格条目 | `block`，4 条待补证据，无结论 |
| 「中区融合用户流失是不是比东区严重」 | 口径命中，但样本 180 户 < 500 户下限 | `block`，`dataCheck=false`，只给证据缺口 |
| 「本周净增为什么转负」 | 双闸门均通过 | `allow` + `caveat`（须标注原因假设） |

> v1.0.0 修订记录：初版只有「口径命中分」一道闸门，导致样本仅 180 户的分区对比被放行。新增 `dataCheck` 第二道闸门后，T5-3 由 allow 纠正为 block。

## Skill ⑥ 工作流 `workflow.ops-loop` v1.0.0 · 端到端链路

```
① 数据入库   WEEKS / MIDWEEK 常量（5 周周报 + 周中快报）
   ↓
② 指标复算   metrics()：一次算出 24 个字段，全部可复算
   ↓
③ 结构化判断 analyzeWeek()：结论 + 依据 + 待补证据
   ↓
④ 追问/推演  multiTurn() → whatIfAddStaff() / staffingAdjust()
   ↓
⑤ 证据校验   evidenceCheck() 双闸门 → 放行或拦截
```

**换数流程**（复用本 Skill 到新一周）：替换 `engine.js` 中 `WEEKS` 数组与 `MIDWEEK` 对象 → `node tools/run-tests.js` 复跑 20 条用例 → 全绿即视为数据接入完成。不改任何判断逻辑。

**版本**：Skill ①–⑤ 与 Agent 同步版本化，本次统一 `v1.0.0 / build 20261125.3`。
